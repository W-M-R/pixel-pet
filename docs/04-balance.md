# 平衡设计与调参记录

## 最终参数

| 参数 | 值 |
|---|---|
| 饱食周期 | **8 小时**（当前代码是 12） |
| 心情周期 | 18 小时（不变） |
| 清洁周期 | 72 小时（不变） |
| 看家速率 | **0.9 枚/小时** |
| 看家时长上限 | **10 小时** |
| 状态系数 | 三维乘法，范围 **0.58 ~ 1.35**（见下） |
| 上线奖励 | **+1 枚**，间隔 ≥5 小时 |
| 普通粮价格 | **7 枚** |

## 进食节奏

饱食周期 8 小时，但阈值不是 0：

| 阈值 | 时点 | 表现 |
|---|---|---|
| 0.4 | 4.8h | 开始报「饿了」 |
| 0.15 | 6.8h | 「很饿」 |

**实际约每 5-7 小时喂一次 = 4.3 次/天。**

## 状态系数：三维乘法

```
系数因子 = (0.70 + 0.30 × 饱食) × (0.45 + 0.55 × 心情) × (0.85 + 0.15 × 清洁)
状态系数 = 0.3 + 系数因子 × 1.05          // 范围 0.58 ~ 1.35
```

压缩区间的宽度即权重。**心情区间最宽（0.55），惩罚最重**：

| 心情 | 系数 | 相对满心情 |
|---|---|---|
| 1.0 | 1.31 | 100% |
| 0.6 | 1.09 | 83% |
| 0.2 | 0.87 | 66% |
| 0.0 | 0.75 | **58%** |

完整推导与"为什么不用加权平均"见 [01-economy.md](01-economy.md#状态系数三维乘法)。

## 收支平衡表

按"全吃普通粮（7 枚）"、各维度自然衰减计算：

| 使用模式 | 离线段 | 总收入 | 支出 | 结余 |
|---|---|---|---|---|
| 4 次/天 | 8+5+5+6h | **28.5** | 28 | **+0.5** |
| 3 次/天 | 8+8+8h | **26.3** | 21 | +5.3 |
| 2 次/天 | 12+12h | **19.6** | 14 | +5.6 |
| 1 次/天 | 24h | **8.2** | 7 | +1.2 |

**四种模式结余都在 +0.5 ~ +5.6 之间**，符合"吃普通粮基本打平"的目标。

### 心情长期很差时（只喂食不陪玩）

| 使用模式 | 总收入 | 支出 | 结余 |
|---|---|---|---|
| 4 次/天 | 25.9 | 28 | **−2.1** ← 入不敷出 |
| 2 次/天 | 19.3 | 14 | +5.3 |

一天 4 次却不陪玩会**倒亏**——因为喂食频繁意味着支出高，
而心情差压低了系数。这正是想要的：不能只喂饭不陪玩。

想吃罐头（14）或小鱼干（32）必须省着吃或靠成就攒。

## 调参过程

记录下来是因为**中间几版都有明显问题**，避免以后又改回去。

### 第 1 版：普通粮免费

```
看家 2 枚/h，上限 12h，普通粮 0 枚
→ 日收益 46 枚，必要支出 0
```

**问题**：硬币没有必须花的地方，会无限累积失去意义。
这是设计里明确要避免的"钱多到没意义"。

### 第 2 版：普通粮 5 枚

```
看家 2 枚/h，上限 12h，上线 +3
→ 4 次/天：收 54，支 20，结余 +34
```

**问题**：结余太多，等于普通粮的价格形同虚设。

### 第 3 版：发现"不奖励勤快"

用"离开那一刻的状态"算系数时：

```
4 次/天：结余 +34
2 次/天：结余 +34      ← 一样！
```

**问题**：开得越勤，每次离线越短，总收益反而没优势——
等于**惩罚勤快的玩家**，和"照顾好宠物"的初衷相反。

**解法**：系数改用**离线期间的平均状态**。
一天 2 次意味着宠物有 4 小时饿着，平均状态低 → 系数低 → 收益降。

### 第 4 版：降速率 + 提价

```
看家 1.0 枚/h（原 2.0），上限 10h（原 12），
上线 +1（原 3），普通粮 7 枚（原 5）
→ 结余全部落在 ±5 枚
```

**问题**：系数只看饱食，心情和清洁再差也不扣钱。

### 第 5 版（最终）：三维乘法 + 微调速率

改成三维压缩乘法后，系数整体上移（清洁周期长，长期接近 1.0），
结余涨到 +6~11，于是把速率从 1.0 降到 0.9、系数区间从
`0.4+f×1.1` 收到 `0.3+f×1.05`：

```
看家 0.9 枚/h，上限 10h，上线 +1，普通粮 7 枚
状态系数 = 0.3 + (三维压缩乘积) × 1.05    // 0.58 ~ 1.35
→ 结余 +0.5 ~ +5.6，且心情差会明显扣钱
```

## 平均状态的推导

三条线都是线性衰减，所以平均值用梯形法就是精确解：

```
若 离线时长 ≤ 周期:
    平均 = (1.0 + (1 - 离线/周期)) / 2 = 1 - 离线/(2×周期)
若 离线时长 > 周期:
    平均 = (周期 × 0.5) / 离线时长        ← 衰减到 0 后就一直是 0
```

三维数值：

| 离线 | 饱食(8h) | 心情(18h) | 清洁(72h) | 系数 | 收益 |
|---|---|---|---|---|---|
| 2h | 0.88 | 0.94 | 0.99 | 1.28 | 2.3 |
| 5h | 0.69 | 0.86 | 0.97 | 1.17 | 5.3 |
| 8h | 0.50 | 0.78 | 0.94 | 1.08 | 7.8 |
| 10h | 0.40 | 0.72 | 0.93 | 1.02 | **9.2** |
| 12h | 0.33 | 0.67 | 0.92 | 0.98 | 8.8 |
| 24h | 0.17 | 0.38 | 0.83 | 0.80 | 7.2 |
| 48h | 0.08 | 0.19 | 0.67 | 0.70 | 6.3 |

注意 **10h 之后收益开始下降**（9.2 → 8.8 → 7.2 → 6.3）：
时长撞上限不再增长，但系数继续跌。
这是刻意的——"长时间不管"应该有代价，且不需要额外的惩罚规则。

也注意**清洁在 48h 时还有 0.67** —— 周期 72h 决定了它天然是低频维护项，
这也是它权重最低（区间只有 0.15）的原因。

## 食物性价比

| 档位 | 价格 | 满值时能管 | 小时/枚 |
|---|---|---|---|
| 剩饭 | 0 | 2.4h | ∞ |
| 普通粮 | 7 | 5.6h | **0.80** |
| 罐头 | 14 | 8.0h | 0.57 |
| 小鱼干 | 32 | 8.0h | 0.25 |

**普通粮性价比最高**，这是刻意的：它应该是日常主力。
罐头和小鱼干卖的是附加效果（心情、buff），不是饱食效率。

## 成就的作用

日常收支打平意味着**光靠日常玩不起高级食物**。

成就总量 1335 枚 ≈ 53 天日常开销，是长期激励的主要来源。
分布上前期密集（首次喂食 10、连续 3 天 20），后期稀疏但金额大
（相伴 100 天 300），符合"新手期给正反馈、长期给目标"的常规节奏。

## 需要实测验证的

文档里的数字都是算出来的，以下需要真实体验后调整：

- **4.3 次/天是否太频繁**。8 小时周期可能让人觉得"缠人"，
  如果实测烦躁，退回 10 小时（约 3.4 次/天）。
- **结余 ±5 枚是否太紧**。如果玩家长期买不起罐头会失去目标感，
  可以把看家速率提到 1.1。
- **小鱼干 32 枚是否定价过高**。需要约 1.5 天的结余才买得起一份。

调参优先改**看家速率**，它是唯一能整体缩放收入而不影响节奏的旋钮。

若要单独调整"心情有多重要"，改心情的压缩区间下界
（现在是 0.45，越小惩罚越重），不要动其他维度。
