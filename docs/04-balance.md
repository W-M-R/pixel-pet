# 平衡设计与调参记录

## 最终参数

| 参数 | 值 |
|---|---|
| 饱食周期 | **8 小时**（当前代码是 12） |
| 心情周期 | 18 小时（不变） |
| 清洁周期 | 72 小时（不变） |
| 看家速率 | **1.0 枚/小时** |
| 看家时长上限 | **10 小时** |
| 状态系数 | `0.4 + 平均状态 × 1.1` → 范围 0.4 ~ 1.5 |
| 上线奖励 | **+1 枚**，间隔 ≥5 小时 |
| 普通粮价格 | **7 枚** |

## 进食节奏

饱食周期 8 小时，但阈值不是 0：

| 阈值 | 时点 | 表现 |
|---|---|---|
| 0.4 | 4.8h | 开始报「饿了」 |
| 0.15 | 6.8h | 「很饿」 |

**实际约每 5-7 小时喂一次 = 4.3 次/天。**

## 收支平衡表

按"全吃普通粮（7 枚）"计算：

| 使用模式 | 离线段 | 看家收益 | 上线奖励 | 总收入 | 支出 | 结余 |
|---|---|---|---|---|---|---|
| 4 次/天 | 8+5+5+6h | 25.7 | 4 | **29.7** | 28 | **+1.7** |
| 3 次/天 | 8+8+8h | 22.8 | 3 | **25.8** | 21 | +4.8 |
| 2 次/天 | 12+12h | 15.3 | 2 | **17.3** | 14 | +3.3 |
| 1 次/天 | 24h | 5.8 | 1 | **6.8** | 7 | **−0.2** |

**四种模式结余都在 ±5 枚内**，符合"吃普通粮基本打平"的目标。

想吃罐头（14）或小鱼干（32）必须省着吃或靠成就攒。

## 调参过程

记录下来是因为**中间几版都有明显问题**，避免以后又改回去。

### 第 1 版：普通粮免费

```
看家 2 枚/h，上限 12h，普通粮 0 枚
→ 日收益 46 枚，必要支出 0
```

**问题**：硬币没有必须花的地方，会无限累积失去意义。
这是设计里明确要避免的"钱多到没意义"。

### 第 2 版：普通粮 5 枚

```
看家 2 枚/h，上限 12h，上线 +3
→ 4 次/天：收 54，支 20，结余 +34
```

**问题**：结余太多，等于普通粮的价格形同虚设。

### 第 3 版：发现"不奖励勤快"

用"离开那一刻的状态"算系数时：

```
4 次/天：结余 +34
2 次/天：结余 +34      ← 一样！
```

**问题**：开得越勤，每次离线越短，总收益反而没优势——
等于**惩罚勤快的玩家**，和"照顾好宠物"的初衷相反。

**解法**：系数改用**离线期间的平均状态**。
一天 2 次意味着宠物有 4 小时饿着，平均状态低 → 系数低 → 收益降。

### 第 4 版（最终）：降速率 + 提价

```
看家 1.0 枚/h（原 2.0），上限 10h（原 12），
上线 +1（原 3），普通粮 7 枚（原 5）
→ 结余全部落在 ±5 枚
```

## 平均状态的推导

饱食线性衰减，所以平均值用梯形法就是精确解：

```
若 离线时长 ≤ 周期:
    平均 = (1.0 + (1 - 离线/周期)) / 2 = 1 - 离线/(2×周期)
若 离线时长 > 周期:
    平均 = (周期 × 0.5) / 离线时长        ← 衰减到 0 后就一直是 0
```

数值（周期 8 小时）：

| 离线 | 平均饱食 | 状态系数 | 看家收益 |
|---|---|---|---|
| 5h | 0.69 | 1.16 | 5.8 |
| 6h | 0.62 | 1.08 | 6.5 |
| 8h | 0.50 | 0.95 | 7.6 |
| 10h | 0.40 | 0.84 | 8.4 |
| 12h | 0.33 | 0.77 | 7.7 |
| 24h | 0.17 | 0.59 | 5.9 |

注意 **12h 之后收益开始下降**（8.4 → 7.7 → 5.9）：
时长撞上限不再增长，但系数继续跌。
这是刻意的——"长时间不管"应该有代价，且不需要额外的惩罚规则。

## 食物性价比

| 档位 | 价格 | 满值时能管 | 小时/枚 |
|---|---|---|---|
| 剩饭 | 0 | 2.4h | ∞ |
| 普通粮 | 7 | 5.6h | **0.80** |
| 罐头 | 14 | 8.0h | 0.57 |
| 小鱼干 | 32 | 8.0h | 0.25 |

**普通粮性价比最高**，这是刻意的：它应该是日常主力。
罐头和小鱼干卖的是附加效果（心情、buff），不是饱食效率。

## 成就的作用

日常收支打平意味着**光靠日常玩不起高级食物**。

成就总量 1335 枚 ≈ 53 天日常开销，是长期激励的主要来源。
分布上前期密集（首次喂食 10、连续 3 天 20），后期稀疏但金额大
（相伴 100 天 300），符合"新手期给正反馈、长期给目标"的常规节奏。

## 需要实测验证的

文档里的数字都是算出来的，以下需要真实体验后调整：

- **4.3 次/天是否太频繁**。8 小时周期可能让人觉得"缠人"，
  如果实测烦躁，退回 10 小时（约 3.4 次/天）。
- **结余 ±5 枚是否太紧**。如果玩家长期买不起罐头会失去目标感，
  可以把看家速率提到 1.1。
- **小鱼干 32 枚是否定价过高**。需要约 1.5 天的结余才买得起一份。

调参优先改**看家速率**，它是唯一能整体缩放收入而不影响节奏的旋钮。
