# 食物系统

## 四档

| 档位 | emoji | 价格 | 恢复饱食 | 满值时能管 | 附加效果 |
|---|---|---|---|---|---|
| 剩饭 | 🥣 | **0**（无限） | 30% | 约 2 小时 | — |
| 普通粮 | 🍚 | 7 | 70% | 约 6 小时 | — |
| 罐头 | 🥫 | 14 | 100% | 约 8 小时 | 心情 +10% |
| 小鱼干 | 🐟 | 32 | 100% | 约 8 小时 | 心情 +25%，24 小时内看家收益 ×1.3 |

## 为什么有免费档

**保证永不卡死。**

如果所有食物都要钱，一个长期不登录的用户回来时可能没钱喂饭，
宠物一直饿着 → 收益系数低 → 更没钱 → 死循环。

"剩饭"这一档抄的是猫咪后院的 Thrifty Bitz（免费食物无限供应）。
它只恢复 30%（约 2 小时），够救急但明显不够用，所以用户有动力买普通粮。

## 为什么主粮要收钱

**如果普通粮免费，硬币就没有必须花的地方。**

早期方案是"普通粮免费，硬币只买高级食物"，但验算发现日收益 46 枚
而必要开销为 0，硬币会无限累积、失去意义。这正是设计里要避免的
"钱多到没意义"。

现在普通粮 7 枚、一天约 4 顿 = 28 枚/天，与日收益 29.7 枚基本打平。
详见 [04-balance.md](04-balance.md)。

## "能管多久"的显示规则

这是玩家最需要的信息，比"恢复 70%"直观得多。

```
能管多久 = 恢复比例 × 饱食周期(8 小时)
```

### ⚠️ 必须注意的坑

恢复是**加到当前值上并封顶 100%**，所以：

- 饱食 0% 时吃罐头（+100%）→ 到 100%，管 8 小时 ✅
- 饱食 50% 时吃罐头（+100%）→ 只到 100%，**实际只补了 50%**，管 4 小时

所以 UI 文案必须写「**满值时**约 8 小时」，不能写「约 8 小时」，
否则用户会觉得被骗。

更好的做法是**动态显示**：按当前饱食值算出这一口实际能补多久。

```swift
/// 这份食物在当前状态下实际能维持多久
func effectiveHours(for food: Food, currentSatiety: Double) -> Double {
    let after = min(1.0, currentSatiety + food.restore)
    let gained = after - currentSatiety
    return gained * (PetState.Decay.hunger / 3600)
}
```

动态显示的好处是能顺便提示"现在吃罐头浪费了"，引导玩家在饿透时才用好食物。

## 不做背包

买了立即用。理由：
- 省掉一整套背包 UI（列表、数量、堆叠、丢弃）
- 宠物 app 的核心是照顾，不是资源管理
- 没有"囤货"就没有"什么时候用"的决策负担

代价是不能"批量买 10 份普通粮"，但每次喂食本来就要点开选择器，
多点一下不算负担。

## 不做食物变质

考虑过"食物会过期"这类设计，否决理由：
- 需要背包（见上）
- 增加负面情绪（打开发现食物坏了），而宠物 app 应该是放松的
- 猫咪后院、Pou 都没有这个设计

## 小鱼干的 buff

24 小时内看家收益 ×1.3。

这让高价食物有超出"填饱肚子"的价值，形成"投资"感：
花 32 枚，如果这 24 小时里正常收益 30 枚，buff 能多赚 9 枚。
单看不划算，但配合心情 +25% 带来的状态系数提升，实际回报更高。

**这是刻意设计成"略微亏本"的** —— 它的价值在于让玩家有"经营"的余地，
而不是最优解。如果 buff 收益大于成本，就变成"必须买"，反而没了选择。

buff 到期时间存在 `PetWallet.boostUntil`，而非 `PetState`——
它是经济系统的一部分，换宠物不该清除。

## UI 形态

喂食按钮点开一个选择器（sheet 或 popover），四个横向卡片：

```
┌──────────┬──────────┬──────────┬──────────┐
│    🥣    │    🍚    │    🥫    │    🐟    │
│   剩饭    │  普通粮   │   罐头    │  小鱼干   │
│   免费    │   7 枚    │  14 枚    │  32 枚    │
│  约2小时  │  约6小时  │  约8小时  │  约8小时  │
│          │          │  心情+10% │ 心情+25%  │
│          │          │          │ 收益×1.3  │
└──────────┴──────────┴──────────┴──────────┘
```

买不起的置灰但仍可点（点了提示"硬币不够"），不要直接隐藏——
让玩家看到目标才有攒钱动力。
