# UI 像素图标 — 自绘

## 为什么自绘

原来 UI 层一律用 Apple emoji（🍖🎾🛁🪙🥣🍚🥫🐟）当图标。两个问题：

1. **风格对撞**：emoji 是高分辨率渐变矢量风，紧贴 4 倍放大的像素猫时
   会把像素感彻底压掉
2. **不可控**：不同 iOS 版本的 emoji 字形会变，无法保证视觉稳定

现有的 `Assets/ui/emotes.png`（Tomcat94, CC0）只有抽象符号
（心/音符/水滴/感叹号），**没有食物、球、浴缸这类具体道具图标** ——
见 `Sources/Scenes/RoomSpriteSheet.swift` 的 `Emote` 注释。

所以自绘。

## 授权

**形状 100% 原创，无第三方素材。** 配色取自 `Sources/Views/PixelStyle.swift`
的木色体系（同样是本项目原创）。

因此这份素材：
- 无需署名
- 无授权限制
- 可自由用于 App Store 截图、宣传图（与 OGA 素材不同，那些预览图不可用）

## 生成方式

`tools/make_ui_icons.py`，ASCII 点阵 + 调色板字典。
沿用 `tools/make_sleep.py` 建立的模式 —— 手绘点阵而非算法变形，
因为像素画的形状信息太密，算法变形会破坏轮廓。

```bash
python3 tools/make_ui_icons.py
```

输出 `Assets/ui/icons.png`，176×16，11 个 16×16 图标横向排列。

## 尺寸约束

图标是 **16×16 源像素**，显示时应为 16 的整数倍（16/32/48pt），
否则会出现半像素边。

`PixelIconView` 的 `size` 参数默认 32。UI 里用 `Pixel.u(n)` 传值，
`Pixel.unit = 4`，所以 `u(4)=16`、`u(6)=24`、`u(8)=32` 都合法。

⚠️ `u(6)=24` 不是 16 的整数倍，是 1.5 倍 —— 实测在 3x 屏上
24pt = 72 物理像素，16 源像素 → 每像素 4.5 物理像素，非整数。
目前观感可接受（图标本身色块较大），但若发现边缘发虚，
应改用 `u(4)` 或 `u(8)`。

## 加新图标

1. 在 `tools/make_ui_icons.py` 的 `ICONS` 字典加一个 16 行 × 16 列的点阵
2. 图例字符要在 `PAL` 里有定义，否则脚本会报错退出
3. 加进 `ORDER` 列表（**只能追加到末尾**，否则会打乱已有索引）
4. 在 `Sources/Views/PixelIcon.swift` 的 `PixelIcon` enum 末尾加对应 case
5. 重跑脚本

脚本会校验每个点阵的行列数，写错会明确报错而不是静默出错图。
